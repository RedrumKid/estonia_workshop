# install via pip

writte or copy: `pip install electrokitty`

# important note for windows

You will have to install Microsoft Build Tools: avalable at:

https://visualstudio.microsoft.com/downloads/

Install Build Tools for Visual Studio

Make sure to mark the C++ development suite


# important note for Mac and Linux users

You will need a C++ compiler, such as g++ that is compatible with C++ 17.0 or higher

You can install it via your distros application manager (apt, etc.) or download and install manually
